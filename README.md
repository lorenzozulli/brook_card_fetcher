# 💀 Brook Card Fetcher

## A telegram bot that uses APIs from [apitcg.com](https://apitcg.com) to fetch card data and displays them in a chat.

### ✅ Main features
1. Card Fetching: Choose a TCG and type the name of the card to get the desired result.
2. Card posting: If you click on a card, the card info will be displayed in the bot chat, ready to be shared with your friends!
